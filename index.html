1. What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of websites.

Basic HTML Example:

<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>

<body>
    <h1>Hello World!</h1>
    <p>This is my first website.</p>
</body>
</html>

Important HTML Tags

<h1> : Creates a heading.

<p> : Creates a paragraph.

<img> : Adds an image.

<a> : Creates a link.

<button> : Creates a button.

2. What is CSS?

CSS stands for Cascading Style Sheets. It is used to make websites look beautiful. You can change colors, sizes, backgrounds and layouts.

Basic CSS Example:

body {
    background-color: lightblue;
    font-family: Arial;
}

h1 {
    color: blue;
    text-align: center;
}

p {
    font-size: 18px;
}

Important CSS Properties

color : Changes text color.

background-color : Changes background.

font-size : Changes text size.

margin : Adds outside spacing.

padding : Adds inside spacing.

border : Adds a border.

3. What is Java?

Java is a programming language used to create applications, desktop programs and backend systems. It is different from JavaScript.

Basic Java Example:

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello World!");

    }

}

Important Java Concepts

int : Stores whole numbers.

double : Stores decimal numbers.

String : Stores text.

if : Makes decisions.

for : Repeats instructions.

System.out.println() : Prints text.
