1. What is HTML?

HTML stands for HyperText Markup Language. It creates the structure of websites.

Example:

<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>

<body>
    <h1>Hello World!</h1>
    <p>My first website.</p>
</body>
</html>

Important HTML Tags

<h1> = Heading

<p> = Paragraph

<img> = Image

<a> = Link

<button> = Button

2. What is CSS?

CSS stands for Cascading Style Sheets. It controls the appearance of websites.

Example:

body {
    background-color: lightblue;
    font-family: Arial;
}

h1 {
    color: blue;
    text-align: center;
}

Important CSS Properties

color = Text color

background-color = Background color

font-size = Text size

margin = Outside spacing

padding = Inside spacing

border = Border around an element

3. What is Java?

Java is a programming language used to create applications and software.

Example:

public class Main {

    public static void main(String[] args) {

        System.out.println("Hello World!");

    }

}

Important Java Concepts

int = Whole numbers

double = Decimal numbers

String = Text

if = Conditions

for = Loops

System.out.println() = Print text
